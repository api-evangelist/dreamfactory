DreamFactory 7.7.0 is now the recommended stable release. It's a substantial one: AI agents become governed, human-owned API consumers; a new open-source API Builder lets you author custom REST endpoints without writing scripts; versioned Schema Contracts catch database drift before it reaches your consumers; and the platform baseline moves to Laravel 13.25 and PHP 8.3. Put simply — AI can now do real work against your data under named ownership, scoped permissions, and a full audit trail, and the rest of the release makes your APIs faster to build and harder to break.
